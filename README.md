## 📥 설치 (1분)

1. 게임을 **완전히 종료**합니다.
2. [Releases](https://github.com/SAM7599/No-Such-Place-Korean-Patch/releases/latest)에서 `zip`을 내려받아 압축을 풉니다. (🔑 비밀번호 `0000`)
3. 나온 `.bat` 파일을 실행하고 안내에 따라 `Y`를 누릅니다.
4. 게임 설정에서 언어를 **한국어**로 선택합니다.

> [!TIP]
> 설치 화면에서 `L`을 누르면 **바탕화면 바로가기**가 만들어집니다.
> 이 바로가기로 게임을 켜면 게임 업데이트로 풀린 패치를 자동으로 다시 적용하고, 새 패치가 나왔는지도 확인합니다.
> 새 패치 파일을 컴퓨터에 내려받아 두었다면 그 파일도 찾아서 갱신해 줍니다.

## 🗑️ 제거

같은 `.bat`을 다시 실행하고 `R`을 누르면 원본으로 되돌립니다. Steam의 *게임 파일 무결성 확인*으로도 복구됩니다.
