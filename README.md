## ✨ 포함된 내용

- 📜 메뉴, 설정, 퀘스트, 아이템, 대사 등 게임 텍스트 한국어 번역
- 🔤 한글이 깨지지 않도록 게임 글꼴에 한글 추가
- 🌍 설정의 언어 목록에 한국어 항목 활성화
- 🎬 인트로 영상 한국어 자막
- 📻 URC 채팅 말투와 이름·부서 표기 통일
- 🏷️ 게임 크레딧과 메인 메뉴 좌측 상단에 제작자 표기

---

## 📥 설치 방법

1. 게임을 **완전히 종료**합니다.
2. [Releases](https://github.com/SAM7599/No-Such-Place-Korean-Patch/releases/latest)에서 `NoSuchPlace_KoreanPatch_v*.zip`을 내려받아 압축을 풉니다. (🔑 비밀번호 `0000`)
3. 압축을 풀고 나온 `.bat` 파일을 실행합니다.
4. 안내 화면에서 `Y`로 동의한 뒤, 설치 화면에서 `Y`를 누릅니다.
5. 게임을 실행하고 설정에서 언어를 **한국어**로 선택합니다.

> [!NOTE]
> 게임 폴더는 자동으로 찾습니다. 못 찾으면 **폴더 선택 창(찾아보기)** 이 열리니 NoSuchPlace 폴더를 골라 주세요.

---

## 🗑️ 제거 방법

같은 `.bat` 파일을 다시 실행하고 `R`을 누르면 원본으로 되돌립니다.
Steam의 **게임 파일 무결성 확인**으로도 복구할 수 있습니다.

---

## 🔄 게임이 업데이트되면

- Steam 업데이트가 패치를 원래대로 되돌릴 수 있습니다. 그럴 때는 `.bat`을 다시 실행하세요.
- 설치 화면에서 `L`을 누르면 바탕화면에 **바로가기**가 만들어집니다. 이 바로가기로 게임을 켜면 패치가 풀렸는지 확인해서 알려 줍니다.

> [!WARNING]
> 게임 버전이 크게 바뀌면 새 패치가 나올 때까지 일부 문구가 맞지 않을 수 있습니다.

---

## ⚠️ 알려진 문제

- 기계번역이라 어색한 문장이 있을 수 있습니다.
- 표지판 같은 **이미지 안의 글자**는 번역되지 않았습니다.
- 언어 목록에 `한국어(WIP)`로 표시됩니다. 게임이 번역 중인 언어에 자동으로 붙이는 표기입니다.

## ❓ 자주 묻는 질문

<details>
<summary><b>NPC를 처치하면 "쿠키 부스러기"라고 나옵니다. 오역인가요?</b></summary>

오역이 아닙니다. 게임 속 적 집단의 이름이 원문 그대로 "Cookie Crumbs"이고, 공식 한국어 퀘스트 문구도 "쿠키 부스러기"로 표기합니다.
</details>

<details>
<summary><b>인트로 영상이 나오지 않습니다.</b></summary>

인트로 영상은 게임을 처음 켤 때 한 번만 재생됩니다. 설치할 때 재생 기록을 지우므로, 설치 후 처음 켜면 한국어 자막 영상이 한 번 나옵니다. (설치할 때는 게임을 꺼 두세요.)
</details>

## 🛡️ 백신 오탐 안내

설치 파일이 `.bat`이고 PowerShell로 게임 파일을 교체하기 때문에 백신이 오탐할 수 있습니다.
파일은 메모장으로 열어 직접 확인할 수 있고, 게임 폴더 밖의 파일은 건드리지 않습니다.
자세한 내용은 압축 파일 안의 `AntiVirus_FalsePositive_Notice.txt`를 확인하세요.
